# سامانه مدیریت انتشار محتوا روی نمایشگرهای آسانسور (Digital Signage)

سامانه مدیریت، زمان‌بندی، انتشار و نمایش محتوای دیجیتال روی اندروید باکس‌های نصب‌شده در آسانسورها — بر اساس سند طراحی و نیازمندی‌های نسخه ۱٫۰ (سه اندروید باکس، بستر Wi-Fi، استقرار Docker).

## معماری

```
   مدیر (کامپیوتر/موبایل)
          │  مرورگر
   ┌──────▼───────┐
   │ پنل مدیریتی  │  React + TypeScript (فارسی، RTL)
   └──────┬───────┘
   ┌──────▼────────┐        ┌─────────┐  ┌──────────┐
   │ سرور مدیریت   │────────│  Redis  │  │ Postgres │
   │ Django + API  │        └─────────┘  └──────────┘
   │ + Worker      │  Celery: PDF→تصویر، پیش‌نمایش، اعتبارسنجی
   └──────┬────────┘
          │  Wi-Fi (دانلود با resume + هش SHA-256)
   ┌──────┼──────────────┐
   │      │              │
┌──▼──┐ ┌─▼───┐        ┌─▼───┐
│باکس۱│ │باکس۲│        │باکس۳│   اپلیکیشن Kotlin (Offline-First)
└──┬──┘ └─┬───┘        └─┬───┘
   │      │              │
 نمایشگر نمایشگر      نمایشگر
```

**اصل طراحی:** محتوا قبل از نمایش به حافظه محلی باکس منتقل و از همان‌جا پخش می‌شود؛ بنابراین قطع Wi-Fi داخل آسانسور پخش را متوقف نمی‌کند و صفحه سیاه نشان داده نمی‌شود.

## اجزا

| جزء | مسیر | فناوری |
|---|---|---|
| سرور و API | `server/` | Django 4.2 + DRF + Channels (WebSocket) + Celery |
| پنل مدیریتی | `panel/` | React 18 + TypeScript + Vite + Tailwind (فارسی/RTL) |
| اپلیکیشن باکس | `android/` | Kotlin + Media3 + Room + Retrofit (minSdk 21) |
| استقرار | `docker-compose.yml` + `nginx/` | Docker Compose: gateway, panel, api, worker, scheduler, db, redis |
| مستندات | `docs/` | نصب، انتشار، بکاپ، عیب‌یابی، آزمون، قالب HTML |

## قابلیت‌های کلیدی (نسخه ۱)

- کتابخانه مرکزی محتوا: فیلم (MP4)، صوت (MP3/AAC)، تصویر (JPG/PNG/WebP)، PDF، بسته HTML و متن/اطلاعیه
- پردازش پس‌زمینه: تبدیل PDF به تصاویر صفحات (کیفیت/DPI قابل تنظیم)، پیش‌نمایش، اعتبارسنجی بسته HTML، هش و فراداده
- سازنده برنامه نمایش با ترتیب و تنظیمات هر آیتم (مدت، صدا، نسبت ابعاد، صفحات PDF و …)
- انتشار فوری / زمان‌دار / دوره‌ای / با پایان اعتبار + اطلاعیه با اولویت بالا
- نسخه انتشار تغییرناپذیر (Snapshot) و جایگزینی امن: تا آماده‌شدن کامل نسخه جدید، نسخه قبلی پخش می‌شود
- تفکیک صریح سه وضعیت: «منتشرشده در سرور»، «دریافت‌شده توسط باکس»، «در حال نمایش»
- داشبورد زنده (WebSocket + polling پشتیبان)، فرمان‌ها (لغو، بازگشت به نسخه قبلی، صدا، توقف/ادامه، پاکسازی)
- دانلود با قابلیت ادامه از سر مسیر (HTTP Range) و صحت‌سنجی SHA-256
- اجرای خودکار پس از روشن‌شدن، حالت کیوسک، گزارش پخش و صف گزارش آفلاین
- نقش‌ها: مدیر سامانه / مدیر محتوا / مسئول انتشار / مشاهده‌گر

## شروع سریع (سرور)

```bash
cp .env.example .env         # مقادیر SECRET_KEY و رمزها را تغییر دهید
docker compose up -d --build
# پنل:      http://<server-ip>:8080/
# مستندات کامل: docs/INSTALL.md
```

راهنمای گام‌به‌گام نصب، تنظیم شبکه Wi-Fi، جفت‌سازی باکس‌ها و آزمون میدانی در **[docs/INSTALL.md](docs/INSTALL.md)** آمده است.

## جریان کار مدیر

```
بارگذاری محتوا → آماده‌سازی (worker) → ساخت برنامه نمایش → انتخاب باکس‌ها و زمان
→ انتقال از طریق Wi-Fi → ذخیره محلی روی باکس → نمایش و گزارش وضعیت
```

نکته مهم: **بارگذاری ≠ انتشار**. فایلی که وارد کتابخانه می‌شود خودکار روی نمایشگرها پخش نمی‌شود؛ انتشار فقط پس از ساخت برنامه، انتخاب مقصد و تأیید مدیر انجام می‌شود.

## ساختار مخزن

```
├── server/                 بک‌اند Django (اپ‌ها: accounts, library, playlists, publishing, devices, core)
│   └── core/tasks.py       پردازش محتوا (PDF→تصویر، ffprobe، اعتبارسنجی HTML)
├── panel/                  پنل وب React + TypeScript (صفحات: داشبورد، کتابخانه، برنامه‌ها، انتشار، دستگاه‌ها، گزارش‌ها، کاربران، تنظیمات)
├── android/                اپلیکیشن Kotlin باکس‌ها (دانلود آفلاین، پخش ۶ نوع محتوا، کیوسک)
├── nginx/nginx.conf        گیت‌وی (پروکسی API/WS + سرو media با Range)
├── docs/                   مستندات نصب، انتشار، بکاپ، عیب‌یابی، آزمون و قالب HTML
├── docs/API_CONTRACT.md    قرارداد API (منبع واحد حقیقت بین سرور/پنل/اپ)
└── docker-compose.yml      استقرار کامل
```

## توسعه محلی

```bash
# بک‌اند
cd server && python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate && python manage.py runserver

# پنل (پروکسی به :8000)
cd panel && npm install && npm run dev

# اپ اندروید: پوشه android/ را در Android Studio باز کنید (android/README.md)
```

## محدودیت‌های شناخته‌شده نسخه ۱

- Word/PowerPoint پشتیبانی مستقیم ندارند (تبدیل پیش از بارگذاری یا توسعه بعدی)
- پخش هم‌زمان موسیقی پس‌زمینه با PDF/HTML به نسخه‌های بعدی موکول شده است
- همگامی دقیق بین سه نمایشگر هدف نیست (هر باکس مستقل نمایش می‌دهد)
- این سامانه جایگزین تجهیزات الزامی هشدار و ایمنی آسانسور نیست
- کنترل روشن/خاموش تلویزیون و راه‌اندازی مجدد باکس به امکانات سخت‌افزاری دستگاه بستگی دارد
