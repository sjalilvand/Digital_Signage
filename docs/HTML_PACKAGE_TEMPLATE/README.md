# قالب نمونه بسته HTML

این پوشه یک **بسته HTML آماده انتشار** است (طبق SRS §7).

## ساخت ZIP و انتشار

```bash
cd docs/HTML_PACKAGE_TEMPLATE
zip -r content-package.zip index.html css js assets
```

سپس در پنل: **کتابخانه محتوا → بارگذاری** → فایل `content-package.zip` (نوع: HTML).
پس از «آماده انتشار»، آن را به یک برنامه نمایش اضافه و منتشر کنید.

## ساختار بسته

```
content-package.zip
├── index.html      فایل شروع (الزامی در ریشه)
├── css/style.css
├── js/main.js
└── assets/logo.png
```

## قواعد اعتبارسنجی سرور (خلاصه)

- مسیرهای مطلق (`/...`) و ناامن (`..`) رد می‌شوند
- حداکثر ۵۰۰۰ فایل و سقف حجم استخراج
- فایل شروع باید در ریشه بسته وجود داشته باشد (`index.html` پیش‌فرض)
- بسته باید کاملاً آفلاین کار کند (منابع داخل بسته)

جزئیات کامل: `docs/CONTENT_FORMATS.md`
