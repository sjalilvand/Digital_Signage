# قالب‌های محتوا و محدودیت‌های نسخه ۱

پسوند فایل به‌تنهایی ملاک سازگاری نیست؛ رزولوشن، کدک و نرخ فریم باید روی باکس واقعی آزمایش شود. جدول زیر مرجع رسمی نسخه ۱ است و پس از آزمون میدانی تکمیل/به‌روز شود.

## قالب‌های پشتیبانی‌شده

| نوع | قالب نسخه ۱ | روش نمایش | محدودیت‌ها |
|---|---|---|---|
| فیلم | MP4 (H.264/AAC) | Media3/ExoPlayer | کدک باید روی باکس واقعی آزمایش شود؛ H.265 روی بعضی باکس‌ها سخت‌افزاری نیست |
| صوت | MP3، AAC/M4A | ExoPlayer (صوت + لوگو) | نسخه ۱: آیتم مستقل، بدون ترکیب با محتوای دیگر |
| تصویر | JPG، PNG، WebP | نمایش مستقیم | تصاویر خیلی بزرگ (>8K) ممکن است سنگین باشد؛ ~1080p/2K کافی است |
| PDF | بدون رمز/بدون DRM | تبدیل به تصاویر صفحات در سرور | سقف ۲۰۰ صفحه به ازای هر فایل؛ DPI/کیفیت از تنظیمات |
| HTML | بسته ZIP محلی | WebView محدودشده | آفلاین؛ بدون CDN بیرونی؛ الگوی بسته پایین صفحه |
| متن/اطلاعیه | قالب داخلی | قالب سامانه (عنوان/متن/رنگ/تصویر) | رنگ به شکل `#RRGGBB` |

## قالب‌های خارج از محدوده نسخه ۱

| نوع | وضعیت |
|---|---|
| Word / PowerPoint | تبدیل پیش از بارگذاری (خروجی PDF) یا توسعه بعدی |
| صفحه وب اینترنتی (آنلاین) | قابلیت اختیاری آینده — وابسته به اینترنت ساختمان |
| فایل اجرایی (APK و …) | خارج از محدوده — انتشار محتوا نیست |
| PDF دارای رمز | پشتیبانی نمی‌شود |

## قواعد اعتبارسنجی سرور

- **فیلم/صوت**: خواندن مدت با ffprobe؛ شکست → وضعیت «ناموفق» با پیام فارسی.
- **تصویر**: باز شدن با Pillow و استخراج ابعاد.
- **PDF**: شمارش صفحات و رندر حداکثر ۲۰۰ صفحه؛ PDF خالی/خراب → ناموفق.
- **HTML (ZIP)**: مسیرهای مطلق/`..` ممنوع، حداکثر ۵۰۰۰ فایل، سقف حجم استخراج (۲× حد آپلود)، وجود فایل شروع (`index.html` به‌عنوان پیش‌فرض) در ریشه بسته.
- **متن**: حداقل عنوان یا متن الزامی؛ رنگ‌ها با الگوی hex.

## الگوی بسته HTML

```
content-package.zip
├── index.html          ← فایل شروع (الزامی در ریشه)
├── css/style.css
├── js/main.js
└── assets/logo.png
```

قواعد:
1. همه مسیرها **نسبی** باشند (`css/style.css` نه `/css/style.css`).
2. منابع ضروری (فونت، تصویر، اسکریپت) داخل بسته باشند — بسته باید کاملاً آفلاین کار کند.
3. فایل شروع حتماً `index.html` نام داشته باشد (یا هنگام بارگذاری مقدار «فایل ورودی» را بدهید).
4. `window.open`، دانلود فایل و خروج به برنامه‌های دیگر روی باکس مسدود است.
5. دسترسی JavaScript به قابلیت‌های حساس Android پیش‌فرض غیرفعال است؛ درخواست‌های شبکه به‌جز `file://` با پاسخ 403 مسدود می‌شوند.
6. HTML تعاملی پیچیده یا وابسته به سرویس بیرونی صرفاً با بارگذاری موفق تضمین نمی‌شود — پیش از انتشار روی باکس آزمایش کنید.

نمونه آماده: `docs/HTML_PACKAGE_TEMPLATE/` (این پوشه را ZIP کنید و بارگذاری کنید).

## توصیه‌های انکودینگ فیلم برای باکس‌های ارزان

- Container: MP4 — Video: H.264 High@4.1 — Audio: AAC-LC 128kbps
- رزولوشن: مطابق نمایشگر (معمولاً 1080p افقی یا عمودی)
- Keyframe هر ۲ ثانیه (`-g 60` در 30fps) برای seek و پایداری
- نمونه دستور:
```bash
ffmpeg -i input.mov -c:v libx264 -profile:v high -level 4.1 -g 60 \
  -c:a aac -b:a 128k -movflags +faststart output.mp4
```
