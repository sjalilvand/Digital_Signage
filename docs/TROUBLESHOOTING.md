# راهنمای عیب‌یابی

## سرور

### سرویس‌ها بالا نمی‌آیند
```bash
docker compose ps
docker compose logs api worker scheduler db redis
```
- خطای اتصال db → `db` سالم نیست یا رمز در `.env` تغییر کرده پس از اولین اجرا (volume قدیمی رمز قبلی را دارد؛ رمز را به حالت قبل برگردانید یا volume را با بکاپ بازسازی کنید).
- پورت اشغال است → `GATEWAY_PORT` در `.env` را تغییر دهید و `docker compose up -d` بزنید.

### پردازش محتوا (وضعیت «در حال بررسی» نمی‌گذرد)
- کارگر پردازش: `docker compose logs -f worker`
- اگر محتوا در «بارگذاری‌شده» گیر کرد (مثلاً worker لحظه آپلود از دسترس خارج بود): کتابخانه → محتوا → «پردازش مجدد».
- خطای ffprobe/ffmpeg در ویدئو → کدک پشتیبانی نمی‌شود؛ فایل را به H.264/MP4 تبدیل کنید (docs/CONTENT_FORMATS.md).
- PDF حجیم/سنگین → DPI یا کیفیت JPEG را در «تنظیمات» کم کنید.

### آپلود فایل بزرگ شکست می‌خورد
- `client_max_body_size` در `nginx/nginx.conf` و `MAX_UPLOAD_GB` در `.env` را هماهنگ افزایش دهید.

## دستگاه‌ها

### دستگاه «آفلاین» است
- Wi-Fi باکس وصل است؟ (بسیاری از باکس‌ها LED یا صفحه تنظیمات دارند)
- از باکس: `ping <server-ip>` (در صورت دسترسی ADB) یا مرورگر باکس
- پوشش Wi-Fi در طبقات را دوباره بسنجید (docs/INSTALL.md §3)
- دستگاه مسدود نشده؟ (صفحه دستگاه → «قطع دسترسی»)

### محتوا دانلود نمی‌شود / پیشرفت ۰ می‌ماند
- برنامه روی دستگاه در وضعیت «در انتظار ارتباط» → باکس آنلاین نیست.
- «در حال دریافت» ولی پیشرفت نوسان دارد → افت Wi-Fi؛ طبیعی است، دانلود از سر مسیر ادامه می‌یابد.
- خطای «SHA-256 mismatch» → دانلود خراب؛ خودکار تلاش مجدد می‌شود. اگر تکرار شد، انتشار را لغو و دوباره منتشر کنید.
- فضای باکس پر است → فرمان «پاکسازی فایل‌ها» یا حذف نسخه‌های قدیمی.

### نسخه جدید فعال نمی‌شود (روی «آماده» نمی‌رود)
- همه فایل‌های نسخه باید کامل شوند (نسخه ناقص هرگز فعال نمی‌شود — امنیت جایگزینی).
- اگر فایلی به‌طور کامل شکست خورد، در جزئیات دستگاه «آخرین خطا» را ببینید.

### نمایش
- صفحه سیاه نباید رخ دهد؛ اگر رخ داد: اپ را از Recent‌ها ببندید و باز کنید، سپس لاگ: `adb logcat -s SyncService PlayerController`
- اجرای خودکار پس از برق: باکس Auto-boot دارد؟ حالت کیوسک را طبق docs/INSTALL.md §5 تنظیم کنید.
- صدا پخش نمی‌شود: فرمان set_volume و تنظیم صدا در برنامه + خروجی صوت باکس (آداپتور AUX/HDMI) را چک کنید.

## پنل

### داشبورد زنده به‌روز نمی‌شود
- WebSocket از `/ws/` عبور می‌کند؛ اگر پراکسی دستی دارید هدرهای Upgrade را بدهید (nginx.conf الگوست).
- پنل خودش به polling هر ۱۰ ثانیه برمی‌گردد؛ در بدترین حالت تا ۱۰ ثانیه تاخیر طبیعی است.

### رمز admin فراموش شد
```bash
docker compose exec api python manage.py changepassword admin
```

### ورود دستگاه با کد جفت‌سازی نمی‌شود
- کد منقضی (۲۴ ساعت) یا قبلاً مصرف شده → صفحه دستگاه → «تولید توکن/کد جدید».

## گزارش خطا برای پشتیبانی

هنگام تماس، این‌ها را ضمیمه کنید:
```bash
docker compose ps > diagnostics.txt
docker compose logs --since 1h api >> diagnostics.txt
docker compose logs --since 1h worker >> diagnostics.txt
```
+ نام دستگاه، نسخه اپ (صفحه دستگاه در پنل) و اسکرین‌شات وضعیت انتشار.
